# Поддержка пользователей

Пункт «Поддержка» в боковом меню открывает диалог обращения. После входа пользователь выбирает категорию, вводит тему и текст, при необходимости прикрепляет один файл до 10 МБ. Вставка скриншота в поле сообщения добавляет его как вложение. Текст письма передаётся без HTML.

`POST /api/support` принимает `multipart/form-data`: `MessageType` (до 100 символов), `Header` (до 200), `Text` (до 10 000), необязательный `UploadedFile`. Нужен JWT. Отправитель обращения определяется по текущему аккаунту; его почта используется в Reply-To. Успех возвращается только после приёма письма SMTP-сервером; история обращений в БД не сохраняется.

Настройки в секции `Smtp` конфигурации сервера:

```json
{
  "Smtp": {
    "Host": "smtp.example.com",
    "Port": 587,
    "EnableSsl": true,
    "UserName": "support@example.com",
    "Password": "",
    "FromEmail": "support@example.com",
    "FromName": "YouScriptor",
    "SupportEmail": "ruticker@gmail.com"
  }
}
```

Пароль можно передать через переменную окружения `Smtp__Password`, остальные настройки — через соответствующие переменные `Smtp__Host` и т. д. Пустой `FromEmail` использует `UserName`. При отсутствии настроек или ошибке SMTP API возвращает 503; форма сохраняет введённое обращение для повторной отправки. Исключения SMTP записываются в серверный журнал, но не возвращаются пользователю.

Для Gmail `UserName` — полный адрес аккаунта, например `name@gmail.com`; название сервиса задаётся в `FromName`. В `Password` нужен пароль приложения этого же аккаунта. Инструкция Google: https://support.google.com/accounts/answer/185833?hl=ru. Ошибка SMTP 535 означает, что сервер отклонил учётные данные.

В текущей установке IIS читает настройки из `C:\YT\appsettings.json`. Изменение только файла в исходниках не меняет настройки опубликованного сайта. После изменения SMTP-настроек перезапустите приложение: `IOptions<SmtpOptions>` кеширует значения до перезапуска.
